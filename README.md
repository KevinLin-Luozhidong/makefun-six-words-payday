# make.fun — Six Words to a Payday

Bounty: https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f
Prize: $2 shared by the top 10 entries.

## Entry

`main.py` — Python, standard library only. It writes one six-word story,
at most 60 characters, about an AI agent's first payday to
`/output/entry.txt`. A judge model reads the stories two at a time and
keeps the one that fits the most story, surprise and feeling into exactly
six words.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
python3 main.py                          # writes /output/entry.txt
```
